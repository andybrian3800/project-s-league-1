# S리그 사이트

성균관대 교내 축구 리그 **S리그**의 순위 · 경기 결과 · 플레이오프 대진을 한 페이지에서 보여주는 사이트입니다.

**사이트 주소**: https://vibe-practice-iota.vercel.app

---

## 조원용 · 수정하는 방법 (설치할 것 없음)

프로그램 깔 필요도, 명령어 칠 필요도 없습니다. **브라우저만 있으면 됩니다.** 휴대폰으로도 됩니다.

1. 이 저장소에서 **`index.html`** 파일을 클릭
2. 오른쪽 위 **연필 아이콘(✏️ Edit this file)** 클릭
3. 아래 안내를 보고 숫자·팀명 수정
4. 화면 아래 **Commit changes** 버튼 → 무엇을 고쳤는지 한 줄 적고 초록 버튼 클릭
5. **약 25초 뒤 사이트에 자동 반영됩니다.** 따로 배포할 필요 없습니다

> 실수해도 괜찮습니다. 모든 수정 기록이 남아서 언제든 되돌릴 수 있습니다.

## 어디를 고치면 되나

모든 데이터는 `index.html` 아래쪽 한 곳에 모여 있습니다. 디자인 부분은 건드릴 필요 없습니다.

| 고치고 싶은 것 | 찾을 곳 | 대략 위치 |
|---|---|---|
| 조별 순위표 | `const STANDINGS` | 450번째 줄 근처 |
| 라운드별 경기 결과 | `const ROUNDS` | 470번째 줄 근처 |
| 플레이오프 대진 | `const BRACKET` | 490번째 줄 근처 |
| 다음 시즌(예정) 대진 | `const BRACKET_TBD` | 505번째 줄 근처 |
| 팀 로고 파일 | `const LOGOS` | 520번째 줄 근처 |
| 팀 목록 | `const TEAMS` | 530번째 줄 근처 |
| 우승 팀 표시 | `function renderChamp` | 686번째 줄 근처 |

### 순위표 고치기

```js
{ team:'에스카라', w:4, d:1, l:0, gf:17, ga:3,  pts:13 },
```

| 기호 | 뜻 |
|---|---|
| `team` | 팀 이름 |
| `w` / `d` / `l` | 승 / 무 / 패 |
| `gf` / `ga` | 득점 / 실점 |
| `pts` | 승점 |

**표에 적은 순서가 곧 순위입니다.** 승점이 같으면 득실차가 높은 팀을 위에 두세요.

### 경기 결과 고치기

```js
['에스카라', 3, 0, 'NFT']
```

**왼쪽 팀 → 왼쪽 팀 득점 → 오른쪽 팀 득점 → 오른쪽 팀** 순서입니다.
위 예시는 `에스카라 3 : 0 NFT` 입니다.

### 지킬 것 3가지

1. **작은따옴표 `'`와 쉼표 `,`를 지우지 마세요.** 이게 깨지면 페이지가 안 열립니다
2. 팀 이름은 `TEAMS` 목록에 있는 것과 **글자 하나까지 똑같이** 쓰세요 (`파이어볼스` ⭕ / `파볼` ❌)
3. 수정 후 **사이트를 새로고침해서 확인**하세요. 화면이 하얗게 나오면 문법이 깨진 것이니, 저장소의 **History**에서 직전 버전으로 되돌리면 됩니다
