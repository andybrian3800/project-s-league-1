## 1. 우리가 볼 KPI 3개

문제 정의가 "**정보가 축구동아리 임원진 단톡방에만 있다**"이므로,
KPI도 "단톡방에서는 불가능했던 행동이 실제로 일어났는가"로 잡습니다.

| # | KPI | 계산식 | 무엇을 증명하나 |
|---|---|---|---|
| **1** | **팀 도달률** | `team_select` 의 **총 사용자** ÷ 전체 사용자 | 그냥 구경이 아니라 **자기 팀 정보를 찾으러** 왔다 |
| **2** | **응원 발견율** | `match_open` 의 **총 사용자** ÷ 전체 사용자 | 8/20 개편 가설(응원을 버튼으로 드러내면 발견율이 오른다) 검증 |
| **3** | **재방문율** | 보고서 → 유지 의 **재사용자 비율** | 일회성 구경이 아니라 **정보 창구**로 쓰이는가 |

보조 지표 (여유 있으면):

| 지표 | 계산식 |
|---|---|
| 뭐먹지 전환 | `outbound_click` 총 사용자 ÷ 전체 사용자 |
| 팝업 전환율 | `eat_popup_go` ÷ `eat_popup_show` |
| 응원 실행률 | `cheer` 총 사용자 ÷ `match_open` 총 사용자 |

> **이벤트 수 ≠ 총 사용자**
> `이벤트 수` = 총 클릭 횟수(한 명이 5번 누르면 5) / `총 사용자` = 누른 사람 수(5번 눌러도 1).
> **KPI는 전부 총 사용자 기준**입니다.

# 부록 · 마감 이후에 할 것

## A. 팀원에게 GA 권한 주기

팀원의 **구글 계정 이메일**이 필요합니다.

1. **관리**(좌측 하단 톱니) → 속성 열의 **속성 액세스 관리**
2. 우측 상단 **＋** → **사용자 추가**
3. 이메일 입력 → **"새 사용자에게 이메일로 알리기"** 체크
4. 역할 **분석가** → **추가**

| 역할 | 할 수 있는 것 |
|---|---|
| 뷰어 | 이미 있는 보고서 보기만 (탐색 보고서를 새로 못 만듦) |
| **분석가** | 보고서·탐색을 직접 만들고 저장 ← 이걸 주세요 |
| 편집자 이상 | 설정까지 변경 (굳이 필요 없음) |

계정 전체가 아니라 **속성**에서 주세요. 다른 프로젝트와 안 섞입니다.

## B. 맞춤 측정기준 등록 (다음 시즌용, 3분)

**관리 → 데이터 표시 → 맞춤 정의 → 맞춤 측정기준 만들기**

| 측정기준 이름 | 범위 | 이벤트 매개변수 |
|---|---|---|
| 팀 | 이벤트 | `team` |
| 캠퍼스 | 이벤트 | `campus` |
| 유입 위치 | 이벤트 | `from` |
| 팝업 시점 | 이벤트 | `trigger` |

등록해 두면 **탐색 → 자유 형식** 에서 이렇게 볼 수 있습니다.

| 보고 싶은 것 | 행 | 필터 |
|---|---|---|
| 팀별 클릭 수 | 팀 | 이벤트 이름 = `team_select` |
| 헤더 vs 팝업 | 유입 위치 | 이벤트 이름 = `outbound_click` |
| 어느 팝업이 먹혔나 | 팝업 시점 | 이벤트 이름 = `eat_popup_go` |

`trigger` 값: `time`(입장 10초 후 + 그 뒤 1분마다) / `campus`(캠퍼스 전환 10초 후)

> **8/20 오후부터 팝업은 광고형입니다.** 하루 2회 상한·최소 간격·"한 번 넘어가면 정지"를 전부 뺐습니다.
> 그래서 `eat_popup_show` 는 **사람 수보다 이벤트 수가 훨씬 큽니다**. 팝업 전환율은
> `eat_popup_go` ÷ `eat_popup_show` 를 **총 사용자 기준**으로 계산하세요.
> 이벤트에 실려 오는 `count`(그 사람에게 몇 번째 노출인지)를 보면 **몇 번째에 눌렀는지**도 알 수 있습니다.
